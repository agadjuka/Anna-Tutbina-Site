## Типы документов

| Тип | Что это | Где используется |
|---|---|---|
| `homePage` 🆕 | Синглтон «Главная страница» | вся главная |
| `siteSettings` 🆕 | Синглтон «Настройки сайта»: футер, контакты | футер на всех страницах |
| `tour` | Тур | главная (блок 3), `/tours/[slug]` |
| `customTour` | Индивидуальный тур | главная (блок 8), `/custom-tour` |
| `faq` | Вопрос-ответ | главная (блок 9) |
| `reviewItem` | Отзыв (вложенный тип внутри тура) | главная (блок 7), страницы туров |
| ~~`about`~~ ❌ | Удалён — см. ниже | — |

Оба синглтона в Studio открываются сразу редактором, без списка и кнопки «создать»:
у них фиксированный `documentId` (`homePage`, `siteSettings`), задан в
[`sanity/structure.js`](../../sanity/structure.js).

## Изменения существующих типов

### `tour` — добавлено поле `year`

```
year: number   // «Год проведения», валидация 2020…2100
```

Под переключатель годов в блоке «Ближайшие путешествия». Вкладки лет собираются
**автоматически из данных** — какие годы есть у туров, такие вкладки и будут.
Год не захардкожен, 2028-й появится сам.

⚠️ **Тур без года не попадёт ни в одну вкладку.** Поле нужно проставить вручную —
см. раздел «Что заполнить руками».

### `customTour` — добавлены поля

```
eyebrow: string      // «СОТРУДНИЧЕСТВО»
images: image[≤3]    // фото блока на главной
tags: string[]       // дни рождения, девичники, корпоративные туры, групповые запросы
```

Старые `title`, `mainImage`, `description` не тронуты — страница `/custom-tour`
продолжает работать как работала.

## Что удалено

### Тип `about` («Обо мне») — удалён полностью

Причина: в макете такого раздела нет. Заказчик подтвердил снос.

Удалено из кода:
- `sanity/schemas/about.ts`
- регистрация в `sanity/schemas/index.ts`
- пункт «Обо мне» в `sanity/structure.js`
- `aboutQuery` в `lib/sanity.queries.ts`
- `components/sections/about-section.tsx`
- секция `<section id="about">` в `app/page.tsx`

⚠️ **Данные в датасете остались.** Удаление схемы не удаляет документы: в `production`
лежит 1 документ типа `about`, он теперь показывается в Studio как документ
неизвестного типа. Снести его можно только вручную в Studio или через API —
это осознанно оставлено заказчику, чтобы не потерять текст биографии безвозвратно.

Якорь `/#about` в шапке **сохранён** — его займёт новый блок «О проекте» (блок 2).

## Что заполнить руками в Studio

Порядок: `npm run sanity:dev` → http://localhost:3333

### 1. Проставить год у всех туров (обязательно, иначе блок 3 будет пустым)

| Тур | Даты | Год |
|---|---|---|
| BALI \| SACRED JOURNEY | 22.11 – 2.12 | ? |
| KAŞ \| BE WOMAN (скрыт) | 31 мая – 6 июня | ? |
| BALI \| PADEL CAMP | 18.08 – 27.08 | ? |
| CAPE TOWN | 25.10 – 1.11 | ? |
| CAPE TOWN (4-11) | 4.11 – 11.11 | ? |

### 2. Создать «Главную страницу»

Тексты во всех секциях прописаны как `initialValue` — при первом открытии
подставятся сами. Заполнить нужно фотографии и списки:

- ~~**Первый экран** — 5 фото коллажа~~ — заполнено агентом из Figma, 2026-08-11
- ~~**О проекте** — 2 фото + 3 абзаца текста~~ — заполнено агентом из Figma, 2026-08-11
- **Ценности** — фоновое фото + 6 карточек
- **Кому подойдёт** — 3 фото + 7 пунктов списка + 2 абзаца
- **Создатели** — фото + текст + ссылки на Instagram

### 3. Создать «Настройки сайта»

Слоган и подпись подставятся сами. Заполнить ссылки: Telegram, WhatsApp,
Instagram, группа в Telegram.

### 4. Дополнить «Индивидуальный тур»

3 фото и теги-поводы.

## Правило на будущее

Новое поле контента = **3 правки**: схема в `sanity/schemas/` → запрос в
`lib/sanity.queries.ts` → рендер в компоненте. Пропуск любого шага = поле молча
не появится на сайте.
